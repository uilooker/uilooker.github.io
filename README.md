# UiLooker

A lightweight, browser-based responsive design testing tool to preview any website across real device screen sizes.

## Live Demo

https://uilooker.github.io/

## Overview

UiLooker helps developers and designers quickly verify how a website behaves on different screen resolutions without installing heavy tools or browser extensions.

Enter a URL and instantly preview the site across multiple devices.

## Features

- Instant responsive preview for any public URL
- Predefined device presets for mobile, tablet, and desktop
- Real-time viewport resizing
- Clean and distraction-free interface
- Fully browser-based
- No signup or installation required

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## How It Works

1. Open the application
2. Enter the website URL you want to test
3. Select a device or screen size
4. View the live responsive preview instantly
